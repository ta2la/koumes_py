📁adresář
🟩HTML soubor .html / .htm
📄ostatní soubor

Ovládání

  • Klik na adresář — vnořit se dovnitř
  • Klik na soubor — otevřít v pravém detail panelu
  • Drobečková lišta nahoře — skok o libovolně úrovní zpět
  • Filter input — filtrovat obsah dir; ^ = jen hot dirs

Chroma toolbar (nad panely)

  • ◀ / ▶ — skrýt/zobrazit parent panel
  • 📁 fm — otevřít aktuální dir v file manageru
  • custom / default — přepínač viewer (pro dir s registrovaným type: viewer)
  • 🔗 links — vypsat bidirectional linky [[id]] aktuálního souboru

Control-bar (v dir panelu)

  • ← back — o úroveň výš
  • 🔄 refresh — znovu načíst list
  • 🔥 hot — kotvy / oblíbené dirs
  • 📋 copy — zkopírovat absolutní cestu (selected file nebo aktuální dir)
  • 🗑 delete — přesunout do koše (gio trash, vratné). Cíl: selected file, nebo aktuální dir když nic vybráno.
  • filter — filtr textem; D/F toggle dirs/files

Info bar (tmavý pruh)

  • Horní řádek (vlevo) — cesta (dir nebo file, relativní od nejbližšího index.t2l)
  • Dolní řádek (vpravo) — viewer (HTML co renderuje); NATIVE = prohlížeč renderuje .html přímo, bez viewer wrapperu

WS commandy (přes websocat ws://127.0.0.1:54325)

  • chroma_dir / chroma_file — current dir/file. Selected (přes fs.setSelectedDir/File) má precedenci před viewed.
  • chroma_dir_viewer / chroma_file_viewer — HTML co renderuje aktuální dir/file
  • chroma_setdir <path> — navigovat mid panel
  • chroma_openfm — file manager na aktuální dir
  • chroma_reload — reload mid page (F5 equivalent)
  • chroma_selection — poslední DOM selekce (JSON)
  • chroma_style "<css>" / chroma_class "<cls>" / chroma_unwrap — style/class/unwrap current DOM selection

Bidirectional linky [[id]]

  • Kdekoli v attribute value → chroma je detekuje, klik walk-up hledá nejbližší index.t2l, resolvuje type[id]file, otevře cíl
  • Back-link: konvence usedIn: [[<other_id>]] na cílovém recordu
