# manual - guide to koumes

A walk-through in parts. Each chapter is a directory and carries its own help -
open it with the ❓ button on that chapter, not from here.

| | what it's about |
|---|---|
| `00_start/` | first steps |
| `01_zaklady/` | what applies everywhere in this tree, on the smallest example |
| `02_vytvareni_aplikace/` | how an app is made here - html laid next to the data, not an install |
| `03_jak_se_koumes_pouziva/` | what changes when an agent sits down at the tree |

The numbers are reading order, nothing more. A chapter is a plain directory;
another one is added by creating and naming it next to them.
